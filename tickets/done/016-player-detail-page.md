# 016. Player detail page

**Type:** feature
**Depends on:** 012

## Description

A page per player showing current holdings with each one's gain/loss,
cash, total fees, total dividends, their value chart, and their transaction
history. Link to it from the leaderboard.

## Acceptance criteria

- [x] Holdings table with per-holding gain/loss, cash, fees and dividend totals
- [x] Player's own value chart and transaction list
- [x] Linked from leaderboard; phone-friendly
- [x] Context docs updated per AGENTS.md (STATUS, SPEC, ADRs as relevant)
