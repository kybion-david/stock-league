# 014. Leaderboard (home page)

**Type:** feature
**Depends on:** 012

## Description

The home page everyone checks daily: players ranked by current value, with
€ and % gain/loss, change since yesterday, and a "last updated" timestamp.
Make it fun: medals, emojis, colours for up and down.

## Acceptance criteria

- [ ] Ranked leaderboard with value, total return, day change
- [ ] "Last updated" date shown
- [ ] Looks good on day 1 (no history) and after many days
- [ ] Phone-first layout
- [ ] Context docs updated per AGENTS.md (STATUS, SPEC, ADRs as relevant)
