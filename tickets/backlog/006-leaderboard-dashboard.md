# 006. Leaderboard and dashboard

**Type:** feature
**Depends on:** 004

## Description

The fun part. Build a mobile-first dashboard everyone checks daily:

- Leaderboard: rank, name, current value, € and % gain/loss, change since yesterday
- Line chart of every player's value over time
- Player detail page: holdings, each one's performance, fees
- Fun extras: today's biggest mover, best/worst single pick

## Acceptance criteria

- [ ] Leaderboard, chart, and player detail pages work on a phone
- [ ] Shows "last updated" date
- [ ] Looks good with only 1 day of data (game start) and with many days
- [ ] Docs updated (SPEC features, structure)
