# 003. Scaffold the app and CI

**Type:** chore
**Depends on:** 001

## Description

Create the app skeleton on the chosen stack, with linting, type-checking
and a test runner, plus a CI workflow that runs them on every PR. Include a
mobile-friendly placeholder home page.

## Acceptance criteria

- [ ] App runs locally with one command
- [ ] Lint, typecheck and a trivial test pass locally and in a CI workflow on PRs
- [ ] Placeholder home page looks fine at phone width
- [ ] `docs/SPEC.md` Structure, Commands, Conventions filled in; `AGENTS.md` repo map and `README.md` "Running locally" updated
- [ ] Context docs updated per AGENTS.md (STATUS, SPEC, ADRs as relevant)
