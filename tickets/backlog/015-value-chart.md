# 015. Value-over-time chart

**Type:** feature
**Depends on:** 012

## Description

A line chart showing every player's portfolio value over the game, one
line per player, with a €1,000 baseline. Pick a lightweight chart library
(record the choice in an ADR).

- [ ] €1,000 reference line
- [ ] Readable on a phone; works with 1 data point
- [ ] ADR for the chart library
- [ ] Context docs updated per AGENTS.md (STATUS, SPEC, ADRs as relevant)
